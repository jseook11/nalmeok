   - **실행 확인은 아직**: `ssh JSRd@jswd` 접속이 지금은 사용자 조치가 필요하다. 확인할 것: WebView2 창, 드롭, 탐색기에서 보기.
6. **문서**: 새 앱 기준으로 README와 `docs/usage.md`를 다시 쓴다. 사용자용 문서에는 CLI를 넣지 않는다. Python 앱과 스크립트는 **사용자에게 확인받은 뒤에** 지운다.
7. 작업이 끝나면 브랜치를 푸시하고 draft PR을 연다(main/master에 직접 푸시하지 않는다).
8. **Windows 아이콘·매니페스트**: **보류 — 사용자 결정 필요**. `.exe`에 아이콘을 넣고 애플리케이션 매니페스트를 심으려면 외부 도구(예: 리소스 편집기)가 필요한데, 어떤 도구를 쓸지 정하지 않았다. 지금 `.exe`는 기본 아이콘과 매니페스트로 빌드된다. DPI 인식은 Wails가 직접 설정하므로 매니페스트 없이도 동작한다. 도구를 정하면 `scripts/build_windows_app.sh`에 한 단계로 넣는다.

## 5. 사용자 결정 기록

- 유료 Batch는 필수다(비용 이점의 핵심).
- 폴더를 놓으면 `.md` 하나로 합친다(폴더 안 `<폴더명>.md`).
- 무료 한도가 바닥나면 버튼("유료로 이어서")으로 넘긴다. 자동으로 넘기지 않는다.
- 목록에는 지나간 항목도 남기고 검색할 수 있게 한다.
- 레이아웃은 시안 C(드롭 상자 없음, 창 전체에 드롭, 단순 목록)로 한다. 시안 이미지는 저장소 루트의 `mockups/`(git 추적 안 함)에 있다.
- macOS 스와이프로 이름 변경과 삭제를 한다. 삭제는 목록에서만 지우고 파일은 남긴다.
- 완료 행의 대표 동작은 "Finder에서 보기"다(ChatGPT 프로젝트에 파일을 올리는 용도). 복사는 우클릭 메뉴에 둔다.
- 행을 앱 밖으로 끌어내는 기능은 만들지 않는다(플랫폼마다 따로 구현해야 하므로).
- CLI는 테스트·AI 에이전트용이다. 사용자 문서에는 싣지 않는다.
