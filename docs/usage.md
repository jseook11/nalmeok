# 사용 설명서

설치와 첫 실행은 [README](../README.md)에 있어요. 이 문서는 화면 사용법, 무료·유료, 비용, 키 발급, FAQ를 다뤄요.

## 화면

창은 하나예요. 위쪽에 **무료** / **유료** 토글과 `+`, 그 아래 검색창, 가운데 처리 목록, 아래쪽에 **?**와 **API 키** 버튼이 있어요.

- 목록이 비었으면 가운데에 **음성 파일이나 폴더를 놓으세요**가 보여요.
- **?**를 누르면 결과 위치, 무료·유료, 지원 형식을 짧게 볼 수 있어요.
- **API 키** 버튼을 누르면 키를 넣거나 지울 수 있어요.
- 키가 한 등급뿐이면 그 방식이 선택되고 다른 쪽은 비활성화돼요.

## 키 넣기

키가 없으면 앱을 처음 열 때 **API 키** 시트가 열려요. 시트에 **Gemini API 키가 필요해요.** 안내 문구와 **키 받는 곳** 버튼이 보여요.

1. **무료** 또는 **유료**를 골라요.
2. **API 키 붙여넣기** 칸에 키를 넣어요.
3. **저장**을 눌러요. 과금 없이 키가 맞는지 확인한 뒤 저장해요.
4. **완료**로 시트를 닫아요.

이름은 **무료 1**, **유료 2**처럼 자동으로 붙어요. 목록에는 뒤 4자리만 보여요. 키 오른쪽의 x를 누르면 지울 수 있어요.

### 무료 키와 유료 키

| | 무료 | 유료 |
|---|---|---|
| 처리 | 바로 전사 | Batch(대기 후) |
| 요금 | 0원 | 1시간에 약 74원 |
| 걸리는 시간 | 오디오 길이에 따라 다름 | 보통 10분~1시간 |
| 한도 | 계정마다 하루 사용량이 있어요 | 결제 한도 안에서 |

- 무료 키는 Batch에 쓸 수 없어요.
- 유료 키는 유료(Batch) 처리에만 써요.
- 무료 키를 여러 개 넣으면 하나가 한도에 걸릴 때 다음 키로 넘어가요. 서로 다른 프로젝트의 키를 넣어요.
- **무료** / **유료** 토글에서 고른 방식은 기억해 두고, 다음에 놓는 항목부터 적용해요.

## 사용

### 파일이나 폴더 놓기

전사할 파일이나 폴더를 창 어디에든 끌어다 놓아요. 놓는 즉시 시작하고, 확인 창은 없어요. `+`를 누르거나 목록이 비었을 때 가운데 **음성 파일이나 폴더를 놓으세요**를 눌러 파일 선택 창을 열어도 돼요.

- 받는 형식: `.m4a`, `.mp4`(AAC 오디오), `.mp3`, `.wav`
- 폴더는 바로 아래의 오디오만 써요. 하위 폴더는 보지 않아요.
- 폴더 안 오디오는 이름 순서로 이어요(`2강` 다음 `10강`).
- 폴더에는 오디오를 1~10개까지 넣을 수 있어요.
- PDF가 하나 있으면 용어 참고자료로 같이 보내요. PDF가 둘 이상이면 실패해요.
- 여러 개를 같이 놓아도 각각 처리해요.
- macOS 음성 메모 앱에서 녹음을 바로 끌어 놓아도 돼요. 녹음은 `~/Documents/Nalmeok/음성 메모/`에 원래 이름(`New Recording 12.m4a` 등)으로 저장되고, `.md`도 그 옆에 생겨요. 같은 이름이 있으면 `New Recording 12 (2).m4a`처럼 번호를 붙여요.

### 목록과 상태

최신 항목이 위로 와요. 여러 날에 걸쳐 있으면 **오늘**, **어제**, 날짜로 나눠 보여요. 행마다 이름과 상태 한 줄, 필요할 때 동작 하나가 보여요.

| 상태 | 화면 |
|---|---|
| 처리 중인 항목 | 초록 점 **진행 중 · n분**, 행 아래에 진행 선 |
| 대기 중인 항목(유료) | 황색 점 **기다리는 중 · n분**(제출한 뒤부터), 행 아래에 천천히 움직이는 선 |
| 서버가 붐빌 때 | 황색 점 **Gemini 서버가 붐벼요 · 다시 시도 중**. 앱이 알아서 다시 보내요 |
| 한도를 다 쓴 항목 | 황색 점 **오늘 무료 사용량을 다 썼어요** + **유료로 이어서** |
| 끝난 항목 | 끝난 시각(예: **오늘 21:08**). 이름을 바꿔도 그대로예요 |
| 실패한 항목 | 적색 점 **실패 · 사유** + **다시 시도** |
| 취소한 항목 | **취소됨** + **다시 시도** |

- 행을 누르면 고르고, 완료된 행을 두 번 누르면 `.md`가 열려요.
- 맨 위 검색창에 이름이나 경로 일부를 넣으면 걸러요. 맞는 항목이 없으면 **결과 없음**이 보여요.

### 전사본 칸

상단 오른쪽 끝의 칸 버튼을 누르면 창이 넓어지고 오른쪽에 고른 항목의 전사본이 보여요. 다시 누르면 접히고 창이 원래 너비로 돌아와요. 마지막 상태를 기억해요.

- 제목 아래 한 줄: 끝난 시각 · 오디오 길이 · 무료/유료 · 비용. 유료는 끝나기 전에 **약 n원**(예상), 끝나면 실제 비용이 보여요.
- **복사**는 전사본 전체를 클립보드에 넣고, **Finder에서 보기**(Windows는 **탐색기에서 보기**)는 파일 위치를 열어요.
- 끝나지 않은 항목은 전사본 대신 지금 상태와 안내가 보여요.

### 이름 변경·삭제·복사

행을 마우스 오른쪽 버튼으로 눌러 메뉴를 열어요. 상태에 따라 **열기**, **복사**, **Finder에서 보기**, **취소**, **유료로 이어서**, **다시 시도**, **이름 변경**, **삭제**가 나와요.

macOS에서는 트랙패드로 두 손가락 가로 스와이프하거나 마우스로 행을 왼쪽으로 끌면 오른쪽에 동작 버튼이 나와요. 진행 중인 항목은 **취소**, 끝난 항목은 **이름 변경**과 **삭제**가 나오고, 끝까지 밀면 삭제돼요.

- **이름 변경**: 이름을 고치고 Enter를 눌러요. Esc를 누르면 그만둬요. 완료된 항목은 같은 폴더의 `.md` 파일 이름도 함께 바뀌어요. 같은 이름이 있으면 번호를 붙여요.
- **삭제**: 목록에서만 지워요. 원본 파일과 `.md`는 그대로 남아요. 진행 중인 항목을 지우면 처리가 취소돼요. 4초 동안 **실행 취소**할 수 있어요.
- **복사**: `.md` 내용 전체를 클립보드에 넣어요.

### 결과 파일

- 파일: `강의09.m4a`를 놓으면 같은 폴더에 `강의09.md`가 생겨요.
- 폴더: `ch07`을 놓으면 `ch07/ch07.md`가 생겨요.
- 폴더 안 오디오는 순서대로 이어 붙이고, 사이에 빈 줄을 하나 넣어요.
- 같은 이름이 있으면 `강의09 (2).md`처럼 번호를 붙여요. 덮어쓰지 않아요.
- 내용은 전사 본문만 들어가요. 머리말이나 요약은 넣지 않아요.

원본 폴더에는 `.md` 말고 아무것도 만들지 않아요. 작업 상태는 앱이 따로 보관해요.

### 무료 한도를 다 썼을 때

무료 키가 모두 오늘 한도에 걸리면 그 항목이 **오늘 무료 사용량을 다 썼어요**로 바뀌어요.

1. 유료 키가 있으면 행에 **유료로 이어서**가 보여요. 눌러요. 유료 키가 없으면 그 버튼이 보이지 않으니 **API 키** 시트에서 먼저 넣어요.
2. 이미 끝난 부분은 그대로 두고, 남은 부분만 Batch로 보내요.
3. 끝나면 앞부분과 합쳐 `.md` 하나로 저장해요.

자동으로 유료로 넘어가지는 않아요. 버튼을 눌러야 해요.

### 유료 대기

유료(Batch)는 보통 10분~1시간 걸려요. 창이 열려 있으면 30초마다 상태를 확인하고, 끝나면 알림을 띄우고 `.md`를 저장해요.

앱을 닫아도 작업은 Google 서버에서 계속돼요. 앱을 다시 열면 대기 중인 항목부터 확인해서 마무리해요.

## 비용

유료(Batch)는 1시간 오디오에 약 74원이에요. 출력 분량에 따라 71~76원 사이로 달라져요. 10시간이면 약 730원이에요.

- Gemini 3.8 Flash Batch 요금(입력 $0.375/1M, 출력 $1.875/1M)과 환율 1,400원 기준이에요.
- Batch는 일반 API의 절반 요금이에요.
- 무료 모드는 0원이에요. 대신 계정마다 하루 사용량이 있어요.
- 실제 청구액은 출력 길이와 환율에 따라 조금 다를 수 있어요.
- 유료 항목은 끝나면 Gemini가 알려 준 토큰 수(오디오·텍스트 입력, 출력·생각)로 계산한 실제 비용을 전사본 칸에 보여 줘요. 같은 요금표와 환율을 써요.

## Gemini API 키 발급

### 무료 키

1. [Google AI Studio](https://aistudio.google.com/apikey)에 Google 계정으로 로그인해요.
2. **Create API key**를 눌러요.
3. 결제를 연결하지 않은 프로젝트를 고르고 키를 만들어요.
4. `AIza...`로 시작하는 키를 복사해요.

무료 등급은 바로 전사에만 써요. 하루 사용량이 정해져 있고 Batch는 쓸 수 없어요. 무료 등급은 입력이 Google 제품 개선에 쓰일 수 있어요. 민감한 강의는 유료 키를 쓰세요.

### 유료 키

1. [Google Cloud 결제](https://console.cloud.google.com/billing)에서 결제 계정을 만들어요.
2. 그 결제 계정을 사용할 프로젝트에 연결해요.
3. [Google AI Studio](https://aistudio.google.com/apikey)에서 그 프로젝트를 골라 키를 만들어요.
4. 키를 복사해요.

Batch는 결제가 연결된 프로젝트에서만 동작해요. 키를 만들 때 프로젝트를 잘 확인해요.

키 전체는 만든 직후에만 보여요. 안전한 곳에 따로 보관해요. 앱에는 소유자만 읽을 수 있는 설정 파일로 저장되고, 화면에는 뒤 4자리만 보여요.

## FAQ

**무료 키만 있어도 쓸 수 있나요?**

네. **무료** 모드로 바로 전사해요. 오늘 한도를 다 쓰면 유료 키를 넣어야 이어 갈 수 있어요.

**앱을 닫으면 유료 작업이 멈추나요?**

아니요. Google 서버에서 계속돼요. 앱을 다시 열면 대기 중인 항목을 확인해서 마무리해요.

**MP4도 되나요?**

AAC 오디오가 든 MP4만 돼요. 다른 코덱이면 실패해요. MP3와 WAV도 그대로 넣을 수 있어요.

**같은 파일을 다시 놓으면?**

새 항목으로 처리해요. 기존 `.md`는 지우지 않고 `(2)`를 붙여 새로 저장해요.

**삭제하면 파일도 지워지나요?**

아니요. 목록에서만 지워요. 4초 안에 **실행 취소**를 누르면 되돌아와요.

**전사는 요약해 주나요?**

아니요. 들린 말을 그대로 받아써요. 알아듣기 어려운 부분은 `[불명확]`으로 남겨요.

**폴더에 PDF를 넣으면 뭐가 달라지나요?**

강의에 나오는 전문 용어를 PDF에서 참고해요. PDF 내용을 요약하거나 옮겨 적지는 않아요.
